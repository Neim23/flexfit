Fixed set and rep ranges
Strength 4-5 sets of 3-6. Lean 3-4 sets of 10-15. Stamina 3-4 sets of 15-25.
Rest days included
2 to 6 sessions a week. Every other day is a rest day.

Questions

Is this a real app?

No. FlexFit is a fictional concept. There is nothing to download or buy.

Does the builder use AI?

No. It is a fixed set of rules in script.js, so the same inputs always give the same plan.

Is the plan medical advice?

No. It is a generic sample. If you have an injury or health condition, ask a professional before training.

Can I train with no equipment?

Yes. The Bodyweight setup uses floor space, a doorframe and a towel.
